# Holly Johanna — Art Portfolio

A Neo-Brutalist portfolio site for Holly Johanna's paintings, built with
Next.js (App Router), Tailwind CSS, and Framer Motion.

## Pages

- **Works** (`/`) — a tiled masonry gallery of artwork. Click any piece to
  open a smooth full-screen carousel view with details; use the on-screen
  arrows or the left/right keys to move between pieces, and Escape (or click
  the backdrop) to close.
- **About** (`/about`) — a short page with a photo collage and bio.
- **Contact** (`/contact`) — a simple contact form that emails submissions
  via [Resend](https://resend.com).

All artwork, photos, and copy are currently **placeholders** — see
[Replacing placeholder content](#replacing-placeholder-content) below.

## Getting started

Requires Node 20.9 or newer (Next.js refuses to build on older versions):

```bash
nvm use v24.14.0
npm install
cp .env.local.example .env.local   # then fill in RESEND_API_KEY
npm run dev
```

The site runs at http://localhost:3000.

## Replacing placeholder content

- **Artwork**: edit `src/lib/artworks.ts`. Each entry needs a `src` (put real
  images in `public/works/`), plus `width`/`height` matching the image's
  actual pixel dimensions (this drives the masonry layout, so keep it
  accurate), a `title`, `year`, `medium`, `dimensions`, and `description`.
- **About page photos/copy**: edit `src/app/about/page.tsx` directly, and
  replace the files in `public/about/`.
- **Placeholder images** were generated by `scripts/generate-placeholders.mjs`
  — safe to delete once real images are in place.

## Contact form (Resend)

The contact form posts to `src/app/api/contact/route.ts`, a serverless
function that sends mail via Resend. You need:

1. A free [Resend](https://resend.com) account and an API key.
2. Locally: put it in `.env.local` as `RESEND_API_KEY`.
3. On Vercel: add the same variable under Project → Settings →
   Environment Variables.

`hollyjohanna.com` is verified as a sending domain in Resend, so
`CONTACT_FROM_EMAIL` can be any address on it — `hello@hollyjohanna.com` by
default. These are send-only addresses and need no mailbox behind them.

`CONTACT_TO_EMAIL` controls where messages are delivered (defaults to
`hollyjohanna.robbins@gmail.com`).

## Deployment

This repo is set up to auto-deploy to Vercel on every push to `main` (see
project setup notes in Obsidian for the exact configuration). Environment
variables (`RESEND_API_KEY`, `CONTACT_TO_EMAIL`, `CONTACT_FROM_EMAIL`) must
be added in the Vercel project settings for the contact form to work in
production.

## Tech stack

- [Next.js](https://nextjs.org) (App Router, TypeScript)
- [Tailwind CSS v4](https://tailwindcss.com)
- [Framer Motion](https://motion.dev) for animation (shared-element modal
